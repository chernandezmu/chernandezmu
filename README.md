- 🚀 Trabajo en **Platify**, una app que unifica todas tus plataformas de videojuegos en un solo lugar: progreso, logros y horas jugadas.
- 🎮 Desarrollo **scripts para servidores de FiveM** (frameworks QBCore, ESX, Qbox y standalone).
- 🧠 Lidero un **semillero de investigación** para controlar videojuegos con la mente usando sensores **EEG Emotiv**.
- 🎨 Me apasionan el **diseño gráfico**, la **edición de video** y el contenido digital.
- 📖 Mi sueño: crear un **videojuego narrativo con más de 20 finales**.
